# PyFunc Studio 1.350

Нативная Windows-программа для живой визуализации математики: 2D-графики, 3D-поверхности, поля направлений, неявные кривые и параметрические фигуры.

## Запуск

Запустите `PyFunc.exe`. Настройки сохраняются в `settings.json` рядом с программой при первом изменении.

Требования: Windows 10/11 x64 и Direct3D 11 (входит в Windows). Для `PyFunc.exe` нужен Microsoft Visual C++ 2015–2022 Redistributable x64, для C#-расширений — .NET 10 Runtime x64. Оба установщика, инструкция и скрипт проверки находятся в папке `Дополнительно`. OpenGL не используется: программа рисует через Direct3D 11. В Windows N/KN для экспорта MP4 может понадобиться Media Feature Pack.

## Дополнительные материалы

В папке `Дополнительно` собраны официальные установщики Microsoft:

- `VC_redist.x64.exe` — Visual C++ 2015–2022 Redistributable (x64), нужен для `PyFunc.exe`.
- `dotnet-runtime-10.0.14-win-x64.exe` — .NET 10 Runtime (x64), нужен для C#-расширений и `PluginHost`.
- `README.txt` — инструкция, включая примечание для Windows N/KN и Media Feature Pack.
- `install-prerequisites.ps1` — установка и проверка зависимостей; запускайте от имени администратора.
- `SHA256SUMS.txt` — контрольные суммы установщиков.

OpenGL программе не нужен: графика работает через Direct3D 11, который входит в Windows 10/11. Отдельный установщик DirectX/OpenGL также не требуется, но драйвер видеокарты должен быть актуальным.

## Что нового в 1.350

- Видеоэкспорт H.264/MP4 стал быстрее и компактнее: NV12, BT.709, 1× MSAA, без повторного рендера предпросмотра.
- Новые умолчания видео: 1920×1080, 30 FPS, 8 Мбит/с. Есть пресеты 720p30, 1080p30, 1080p60 и 4K.
- Плавнее 2D/3D: MSAA 2× по умолчанию, выбор 1×/2×/4×/8×, адаптивное качество 3D-сетки при просадке FPS.
- CLI-экспорт видео выполняется без видимого окна и без лишнего рендера видовой сцены.
- Закрытие приложения во время записи удаляет недописанный MP4.
- Собственные звуковые сигналы встроены в exe: завершение — восходящее арпеджио, ошибка — низкий нисходящий сигнал, шпаргалка — короткий тихий клик. Звук завершения не совпадает с системной ошибкой Windows.
- В папке `Дополнительно` собраны официальные установщики Microsoft Visual C++ 2015–2022 x64 и .NET 10 Runtime x64, README и скрипт установки/проверки.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `Ctrl+E` | экспорт видео |
| `Ctrl+,` | настройки |
| `F1` | шпаргалка по командам |
| `Ctrl+K` | палитра команд |
| `Ctrl+N` / `Ctrl+O` / `Ctrl+S` | новый / открыть / сохранить проект |
| `F5` | перезагрузить C#-скрипты |
| `Пробел` | пауза/воспроизведение |

## CLI

```text
PyFunc.exe --screenshot <путь.png> --frames <N> [--2d] [--project <файл.pyfunc.json>]
PyFunc.exe --video <путь.mp4> [--video-seconds <сек>] [--video-size 1920x1080] [--video-fps 30]
```

Папки `assets`, `plugins` и `PluginHost` должны находиться рядом с `PyFunc.exe`. Папка `Дополнительно` нужна только для установки/проверки зависимостей и для работы программы не обязательна.
